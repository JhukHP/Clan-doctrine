# SOP-005 — Работа ралик-отряда

> **Статус:** Черновик  
> **Версия:** 0.1.0  
> **Ответственный:** Руководство клана  
> **Последнее обновление:** 2026-07-27

---

# Цель

Определить роль и принципы работы ралик-отряда.

Процедура помогает:

- эффективно использовать мобильный отряд;
- создавать давление на противника;
- поддерживать общую стратегию команды;
- избегать бессмысленных самостоятельных действий.

---

# Назначение ралик-отряда

Ралик — это специализированный мобильный отряд.

Его основная задача:

- создавать угрозу для противника;
- менять распределение сил врага;
- создавать выгодные условия для основной команды.

Ралик не является отдельной командой вне общей стратегии.

---

# Основные задачи

## Создание давления

Ралик может:

- атаковать неожиданные направления;
- заставлять противника реагировать;
- отвлекать силы от основных точек.

---

## Создание точки возрождения

Одна из ключевых задач:

- найти выгодную позицию;
- установить точку возрождения;
- обеспечить команде альтернативный путь возвращения в бой.

---

## Разведка

Ралик может получать информацию:

- о передвижениях противника;
- о слабых направлениях;
- о расположении сил врага.

---

# Работа с Коллером

Ралик получает задачу от Коллера.

Коллер определяет:

- цель;
- приоритет;
- ожидаемый результат.

Пример:

> "Ралик, создайте давление справа и найдите возможность поставить точку возрождения"

---

# Свобода действий

Из-за характера задач ралик имеет больше свободы, чем обычный отряд.

Однако свобода не означает отсутствие контроля.

Ралик обязан:

- понимать общую ситуацию;
- сообщать важные изменения;
- не выполнять действия, которые вредят общей стратегии.

---

# Коммуникация ралика

Доклады должны быть короткими.

Основной формат:

```
Где:
Что происходит:
Что делаем:
```

Пример:

> "Ралик, заходим в тыл, противник реагирует двумя игроками"

---

# Установка точки возрождения

Перед установкой необходимо учитывать:

- безопасность позиции;
- полезность для команды;
- возможность дальнейшего давления.

Хорошая позиция:

- дает преимущество;
- усложняет действия противника;
- помогает команде быстрее возвращаться.

---

# После установки точки

Ралик сообщает:

- позицию;
- состояние;
- возможности использования.

Пример:

> "Ралик, точка поставлена, безопасна, можно использовать"

---

# Когда ралик должен менять задачу

Ралик может изменить направление работы, если:

- противник полностью перестал реагировать;
- появилась более ценная возможность;
- Коллер изменил приоритет.

При значительном изменении плана необходимо сообщить Коллеру.

---

# Взаимодействие с основными отрядами

Ралик не должен:

- забирать ресурсы команды без причины;
- создавать конфликт задач;
- игнорировать критические точки.

Ралик должен:

- создавать возможности;
- передавать информацию;
- заставлять противника ошибаться.

---

# Типичные ошибки

| Ошибка | Последствие | Исправление |
|--------|-------------|-------------|
| Игра без связи с командой | Потеря пользы | Согласовывать цели |
| Погоня за убийствами | Потеря основной задачи | Ориентироваться на влияние |
| Установка точки без пользы | Потеря времени | Оценивать позицию |
| Игнорирование карты | Несвоевременные решения | Поддерживать связь |

---

# Критерии выполнения

Ралик считается эффективным, если:

- [ ] Создает давление на противника.
- [ ] Предоставляет полезную информацию.
- [ ] Создает возможности для основной команды.
- [ ] Не действует в ущерб общей стратегии.

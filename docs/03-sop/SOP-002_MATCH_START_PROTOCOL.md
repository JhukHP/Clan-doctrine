# SOP-002 — Подготовка к матчу

> **Статус:** Черновик  
> **Версия:** 0.1.0  
> **Ответственный:** Руководство клана  
> **Последнее обновление:** 2026-07-27

---

# Цель

Обеспечить одинаковое понимание состава, ролей и задач перед началом матча.

Процедура нужна для:

- уменьшения хаоса перед стартом;
- быстрой адаптации замен;
- подготовки отрядов к выполнению задач.

---

# Когда применяется

Используется:

- перед рейтинговым матчем;
- перед тренировочным матчем;
- при изменении состава;
- при замене игроков.

---

# Подготовка состава

Перед началом матча должны быть определены:

- Коллер;
- состав отрядов;
- замены;
- специальные роли;
- порядок коммуникации.

---

# Формирование отрядов

Стандартная структура:

```
Отряд

Лидер
+
Напарник лидера

Мастер
+
Напарник мастера
```

При отсутствии игрока:

- используется игрок ротационного состава;
- при необходимости используется резерв;
- сохраняется структура пары насколько возможно.

---

# Проверка готовности

## Лидер отряда проверяет:

- все игроки присутствуют;
- коммуникация работает;
- игроки знают свои роли.

---

## Коллер проверяет:

- количество доступных игроков;
- распределение по отрядам;
- наличие необходимых ролей.

---

# Распределение задач

Перед началом матча Коллер сообщает:

- общий план;
- приоритетные направления;
- особые задачи.

Пример:

> "1 и 2 отряд — основное давление.  
> 3 и 4 — контроль центральных точек.  
> 5 — мобильный резерв.  
> 6 — работа по ситуации."

---

# Правило понимания задачи

Игрок должен понимать:

- что делает его отряд;
- какую цель выполняет;
- кому он сообщает информацию.

Игрок не обязан знать все решения Коллера.

Он обязан понимать свою задачу.

---

# Подтверждение готовности

После получения задачи лидер отряда подтверждает:

Пример:

> "1-й готов"

или:

> "1-й, есть проблема, нужен заменяющий игрок"

---

# Замены перед матчем

Если игрок отсутствует:

1. Лидер сообщает проблему.
2. Определяется замена.
3. Замена получает роль.
4. Лидер объясняет основные ожидания.

---

# Особенности новых игроков

Новый или резервный игрок перед матчем должен знать:

- с кем играет;
- кто его лидер;
- кто его мастер;
- какая его задача.

Не требуется объяснять всю стратегию команды.

Главное — понятная ближайшая задача.

---

# Ошибки подготовки

| Ошибка | Последствие | Исправление |
|--------|-------------|-------------|
| Игрок не знает свою роль | Потеря времени | Проверять состав заранее |
| Замена появляется без объяснения | Нарушение взаимодействия | Назначать пару |
| Все ждут приказов в последний момент | Медленный старт | Подготовка заранее |
| Обсуждение тактики продолжается слишком долго | Нет концентрации | Ограничивать время подготовки |

---

# Критерии выполнения

Подготовка считается успешной, если:

- [ ] Каждый игрок знает свой отряд.
- [ ] Каждый игрок знает свою роль.
- [ ] Лидеры знают задачи.
- [ ] Коллер готов управлять матчем.

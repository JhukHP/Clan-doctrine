# SOP-003 — Работа с точками

> **Статус:** Черновик  
> **Версия:** 0.1.0  
> **Ответственный:** Руководство клана  
> **Последнее обновление:** 2026-07-27

---

# Цель

Создать единый подход к захвату, удержанию и усилению точек.

Процедура помогает:

- быстрее выполнять задачи Коллера;
- сохранять структуру отряда;
- принимать локальные решения без лишней коммуникации.

---

# Основной принцип

Коллер управляет картой.

Отряд управляет выполнением задачи.

Коллер сообщает:

> Что нужно сделать.

Отряд решает:

> Как лучше выполнить задачу.

---

# Получение задачи

После получения задачи лидер отряда должен понять:

- какая точка является целью;
- какая задача поставлена;
- какой результат ожидается.

Примеры задач:

- захват точки;
- удержание точки;
- усиление точки;
- отвлечение противника;
- создание давления.

---

# Подтверждение задачи

Лидер подтверждает получение:

Пример:

> "2-й, принял, идем на B"

Не требуется объяснять весь план действий.

---

# Действия отряда

После получения задачи:

## Лидер

Отвечает за:

- направление движения;
- распределение действий;
- изменение плана при необходимости.

---

## Мастер

Отвечает за:

- эффективность своей пары;
- поддержку действий лидера;
- передачу опыта напарнику.

---

## Напарники

Отвечают за:

- выполнение своей части задачи;
- передачу информации;
- поддержку пары.

---

# Захват точки

При атаке точки отряд должен:

- действовать как единая группа;
- контролировать направления;
- сообщать важные изменения.

Не рекомендуется:

- входить по одному без причины;
- оставлять игроков без задачи;
- игнорировать информацию других отрядов.

---

# Удержание точки

При удержании:

Отряд должен контролировать:

- направления подхода противника;
- состояние точки;
- необходимость поддержки.

Игроки должны избегать:

- бессмысленного выхода из зоны;
- одиночных действий без цели;
- погони за противником в ущерб задаче.

---

# Запрос усиления

Отряд сообщает о необходимости помощи, если:

- невозможно удержать точку текущими силами;
- противник получил численное преимущество;
- потеря точки значительно повлияет на матч.

Формат:

```
Кто:
Где:
Ситуация:
Что нужно:
```

Пример:

> "3-й, точка C, два направления атаки, нужна помощь"

---

# Передача точки другому отряду

Передача контроля происходит:

- по решению Коллера;
- при изменении ситуации;
- при необходимости перераспределения сил.

Перед уходом отряд должен сообщить:

- текущее состояние точки;
- информацию о противнике;
- возможные риски.

---

# Использование пар

Стандартно отряд работает как две пары.

Пары могут:

- двигаться вместе;
- разделяться для создания давления;
- выполнять разные задачи.

Разделение возможно, если:

- есть понятная цель;
- сохраняется связь;
- лидер понимает ситуацию.

---

# Использование игровых меток

Метки используются для:

- обозначения направления;
- указания позиции;
- передачи простой информации.

Метки не заменяют:

- критические сообщения;
- команды;
- важные доклады.

---

# Ошибки при работе с точками

| Ошибка | Последствие | Исправление |
|--------|-------------|-------------|
| Игроки действуют отдельно | Потеря эффективности | Работать парами |
| Нет информации о ситуации | Неверные решения | Давать короткие доклады |
| Отряд не сообщает проблему | Поздняя реакция | Запрашивать помощь раньше |
| Выполнение задачи без понимания цели | Потеря времени | Уточнять задачу |

---

# Критерии выполнения

Процедура считается выполненной, если:

- [ ] Отряд понимает задачу.
- [ ] Лидер контролирует действия.
- [ ] Информация передается своевременно.
- [ ] Отряд сохраняет боеспособность.

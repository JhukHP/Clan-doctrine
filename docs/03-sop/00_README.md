# 03 — Стандартные операционные процедуры

## Назначение

В этом разделе содержатся краткие рабочие процедуры, которые игроки используют при подготовке и во время матчей.

СОП отвечает на вопрос:

«Что следует делать?»

---

## Содержание

Предполагаемые документы:

- Процедуры коммуникации
- Процедуры подготовки к матчу
- Действия отряда
- Экстренные процедуры
- Процедуры ротации

---

## Область применения

Документы СОП описывают действия и ожидаемое поведение.

Они должны быть:

- краткими;
- практичными;
- легко запоминаемыми.

---

## Правила для документов

СОП не должны содержать:

- длинные объяснения;
- теорию;
- программы обучения.

Для объяснений используйте РУКОВОДСТВО.

Для практики используйте ОБУЧЕНИЕ.

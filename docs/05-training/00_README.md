# 05 — Обучение

## Назначение

В этом разделе содержатся программы обучения и упражнения, направленные на повышение индивидуальной и командной эффективности.

---

## Содержание

Предполагаемые документы:

- Индивидуальное обучение
- Парное обучение
- Обучение отряда
- Обучение клана
- Обучение руководителей

---

## Область применения

Документы по обучению объясняют:

- какой навык развивается;
- как его развивать;
- как измеряется успех.

---

## Правила для документов

Каждое обучение должно содержать:

- цель;
- упражнение;
- критерии оценки;
- обратную связь.

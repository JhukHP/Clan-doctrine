# 07 — Межсезонье

## Назначение

В этом разделе содержатся материалы, относящиеся к периодам вне соревновательных сезонов.

---

## Содержание

Предполагаемые документы:

- Экспериментальные тактики
- Развитие руководителей
- Планы тестирования
- Оценка новых игроков

---

## Область применения

Межсезонье используется для:

- обучения;
- экспериментов;
- улучшений.

---

## Правила для документов

Экспериментальные идеи не должны становиться постоянными стандартами без проверки.

# Состав и система ротации

> **Статус:** Черновик  
> **Версия:** 0.1.0  
> **Ответственный:** Руководство клана  
> **Последнее обновление:** 2026-07-27

---

## Назначение документа

Этот документ описывает принципы формирования состава клана и систему ротации игроков.

Цели системы:

- сохранить конкурентоспособность состава;
- обеспечить развитие всех игроков;
- уменьшить зависимость от отдельных участников;
- подготовить игроков резерва к переходу в основной состав.

---

## Принципы состава

### Клан важнее текущего состава

Состав игроков может меняться.

Система должна работать независимо от того:

- кто отсутствует;
- кто временно не играет;
- кто присоединился недавно.

---

### Игрок должен иметь возможность развиваться

Каждый игрок должен понимать:

- где он находится сейчас;
- что ему нужно улучшить;
- как перейти на следующий уровень.

---

### Боеспособность важнее статуса

Место в составе определяется не только прошлым вкладом игрока.

Учитываются:

- текущая форма;
- надежность;
- коммуникация;
- понимание командной игры;
- участие в развитии.

---

## Категории игроков

### Боевой состав

Игроки, которые регулярно участвуют в рейтинговых матчах.

Обычно:

- основные лидеры;
- опытные мастера;
- стабильные игроки отрядов.

---

### Ротационный состав

Игроки, которые регулярно участвуют в играх и могут входить в боевой состав.

Цель:

- поддерживать необходимое количество активных игроков;
- давать возможность развития;
- обеспечивать замену отсутствующих.

---

### Резерв

Игроки, которые:

- развиваются;
- получают игровую практику;
- могут быть привлечены при необходимости.

Резерв является частью системы подготовки состава.

---

## Формирование отрядов

Базовая структура:

- 6 отрядов;
- 4 игрока в каждом;
- Коллер управляет общей ситуацией.

Стандартный отряд:

```
Лидер отряда
+
Напарник лидера

Мастер
+
Напарник мастера
```

---

## Принцип постоянных пар

Основная цель:

создать стабильное взаимодействие между игроками.

Игроки должны регулярно играть вместе, чтобы развивать:

- доверие;
- понимание действий;
- скорость реакции.

---

## Гибкость состава

Постоянство отрядов не означает отсутствие изменений.

Изменения возможны при:

- отсутствии игрока;
- изменении количества активных игроков;
- необходимости развития игрока;
- изменении игровых задач.

---

## Ротация игроков

### Цель ротации

Ротация используется для:

- выполнения игрового требования для сезонной награды;
- развития резерва;
- подготовки замен;
- сохранения устойчивости состава.

---

### Игровое требование для сезонной награды

Чтобы получить сезонный бонус за участие в клановых боях, игрок должен участвовать не менее чем в 30% клановых боёв соответствующего сезона.

Это требование игры, а не внутренняя квота клана.

Ротация помогает планировать участие игроков для выполнения этого требования, но не гарантирует участие в конкретном матче и не отменяет приоритет боеспособности состава.


---

## Правила замены

При отсутствии игрока:

1. В первую очередь используется игрок того же отряда.
2. Если такой возможности нет — используется универсальный игрок резерва.
3. Новый игрок получает место в структуре пары, а не играет хаотично.

Пример:

Был:

```
Мастер
+
Напарник мастера
```

Замена:

```
Мастер
+
Игрок резерва
```

---

## Универсальность резерва

Игрок резерва должен постепенно научиться:

- играть в разных отрядах;
- понимать разные стили игры;
- выполнять разные задачи.

Резерв не должен быть привязан только к одному составу.

---

## Переход игрока из резерва

Игрок готов к переходу в ротационный или боевой состав, если он:

- понимает структуру клана;
- выполняет команды;
- умеет работать в паре;
- предоставляет качественную информацию;
- стабильно играет независимо от отряда.

---

## Ответственность основных игроков

Игроки боевого состава помогают развитию системы.

Их задача:

- не только играть лучше;
- но и помогать другим становиться сильнее.

Особенно это касается:

- мастеров;
- лидеров отрядов;
- опытных игроков.

---

## Оценка развития

Оценка игрока должна учитывать:

| Навык | Оценка |
|------|--------|
| Индивидуальная игра | |
| Коммуникация | |
| Выполнение задач | |
| Работа в паре | |
| Работа в отряде | |
| Самостоятельность | |

---

## Межсезонье

Межсезонье используется для:

- проверки новых игроков;
- экспериментов с составами;
- обучения лидеров;
- проверки новых подходов.

Эксперименты вне рейтинга позволяют улучшать систему без риска для результата.
